# 🎙️ مهیار گپ — mahyar gap

گپ، ویس گروهی، اسکرین‌شیر و رادیوی ۲۴ ساعته — مخصوص رفیق‌ها. یه دیسکورد شخصی و سبک با ظاهر اختصاصی.

![stack](https://img.shields.io/badge/Node.js-20-339933) ![stack](https://img.shields.io/badge/React-Vite-61dafb) ![stack](https://img.shields.io/badge/LiveKit-WebRTC-ff6ea9) ![stack](https://img.shields.io/badge/Railway-ready-8b5cf6)

## ✨ قابلیت‌ها

- 💬 **چت متنی** زنده با تاریخچه، تایپینگ لحظه‌ای، حذف پیام و بج پیام‌های نخونده
- 🎙️ **ویس گروهی** با LiveKit — چراغ صحبت کردن، کیفیت ارتباط و **ولوم جداگانه برای هر نفر** (مثل دیسکورد)
- 📺 **اشتراک صفحه** با کیفیت کامل + صدا
- 📻 **رادیوهای ۲۴ ساعته** با کامند `/mp` — رادیو مستقیم تو ویس پخش می‌شه، با ولوم جدا از صدای بقیه
  - 🇮🇷 پاپ فارسی، 🔥 شوطی، 🌍 پاپ جهانی، 💔 غمگین
  - اگه ویس **۱ دقیقه خالی بمونه**، رادیو خودش قطع می‌شه
- 👥 حضور آنلاین، ورود بی‌صدا، بی‌صدا کردن همه (Deafen)
- 🎨 ظاهر اختصاصی «شفق»: دارک، شیشه‌ای، کاملاً فارسی و راست‌چین
- ⚡ **بهینه برای Railway**: کل اپ توی **یک سرویس** اجرا می‌شه — صفر فشار اضافه به منابع

## 🚀 دِپلوی روی Railway (از گیت‌هاب)

### قدم ۱ — آپلود روی گیت‌هاب

```bash
# داخل پوشه‌ی mahyar-gap
git remote add origin https://github.com/USERNAME/mahyar-gap.git
git push -u origin main
```

> ⚠️ فایل `.env` توی `.gitignore` هست و **آپلود نمی‌شه** — این درسته! کلیدها نباید تو گیت‌هاب باشن.

### قدم ۲ — ساخت سرویس تو Railway

1. برو به [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → ریپو رو انتخاب کن
2. Railway خودش با `Dockerfile` بیلد می‌کنه (چند مرحله‌ای و سبک)
3. برو به سرویس → تب **Variables** → این ۶ متغیر رو بذار:

| متغیر | مقدار |
|---|---|
| `DATABASE_URL` | همون آدرس PostgreSQL خودت |
| `JWT_ACCESS_SECRET` | همون کلید خودت |
| `LIVEKIT_API_KEY` | همون کلید خودت |
| `LIVEKIT_API_SECRET` | همون کلید خودت |
| `LIVEKIT_URL` | `wss://mydiscord-36exol2s.livekit.cloud` |
| `NODE_ENV` | `production` |

4. تب **Settings** → Networking → **Generate Domain** → آدرس عمومی اپت آماده‌ست 🎉

### قدم ۳ — ثبت‌نام و لذت ببر

اولین نفر که ثبت‌نام کنه، کانال‌های پیش‌فرض خودش ساخته می‌شن. بقیه‌ی رفیق‌ها هم ثبت‌نام کنن کافیه.

> 🔒 می‌خوای ثبت‌نام رو محدود کنی؟ توی Railway متغیر `INVITE_CODE` رو با یه کد دلخواه بذار — بعداً موقع ثبت‌نام باید واردش کنن.

## 📻 استفاده از رادیو

اول به یه کانال ویس وصل شو، بعد:

| کامند | کار |
|---|---|
| `/mp` | باز شدن منوی انتخاب رادیو |
| `/mp 1` تا `/mp 4` | پخش مستقیم رادیو |
| `/mp off` | خاموش کردن رادیو |

یا از دکمه‌ی 📻 داخل ویس. هر نفر **ولوم رادیو رو جدا** تنظیم می‌کنه (کارت رادیو داخل ویس).

> نکته‌ی فنی: استریم رادیو **مستقیم** از سرور رادیو به مرورگر هر شنونده می‌ره (نه از طریق سرور تو) — یعنی رادیو هیچ مصرفی از CPU و پهنای باند Railway نداره و فقط state اون توی سرور نگه‌داری می‌شه.

## 🛠 توسعه‌ی محلی (اختیاری)

```bash
npm install
npx prisma generate
npm run dev        # سرور روی :3000 + کلاینت روی :5173
```

برای دیتابیس لوکال، توی `.env` یه `DATABASE_URL` محلی بذار (مثلاً از Docker: `postgres:16`). مایگریشن‌ها با `npx prisma migrate deploy` اعمال می‌شن.

## 🧱 ساختار پروژه

```
mahyar-gap/
├─ prisma/schema.prisma      # اسکیمای دیتابیس (User, Channel, Message)
├─ src/server/               # Express + Socket.IO + LiveKit + منطق رادیو
├─ src/client/               # React + Zustand + livekit-client
├─ Dockerfile                # بیلد چندمرحله‌ای سبک برای Railway
├─ railway.json              # تنظیمات دِپلوی + healthcheck
└─ .github/workflows/ci.yml  # چک بیلد روی هر پوش
```

## 🔐 نکات امنیتی

- کلیدها فقط توی **Variables داشبورد Railway** — هیچ‌وقت تو گیت‌هاب نه
- اگه فکر می‌کنی `JWT_ACCESS_SECRET` لو رفته، یه رشته‌ی تصادفی جدید بذار (همه لاگ‌اوت می‌شن، اشکالی نداره)
- پسوردها با bcrypt هش می‌شن و توکن‌ها JWT ۳۰ روزه‌ان
